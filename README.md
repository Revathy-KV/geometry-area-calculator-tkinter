# Geometry Area Calculator using Tkinter

A simple and user-friendly Python GUI application developed using Tkinter to calculate the areas of basic geometric shapes such as a **Rectangle** and a **Circle**.

---

## 📌 Project Overview

This project demonstrates the use of the Tkinter library in Python to build graphical user interface (GUI) applications. It allows users to input dimensions and instantly compute the area of geometric shapes through an interactive window.

---

## ✨ Features

- Graphical User Interface (GUI) using Tkinter
- Calculates:
  - Area of a Rectangle
  - Area of a Circle
- Simple and intuitive design
- Beginner-friendly Python project
- Suitable for academic labs and mini projects

---

## 🛠 Technologies Used

- Python 3
- Tkinter (Python Standard GUI Library)
- Math module (for circle area calculation)
